# Anteneh AI Video Studio

Private personal AI video-production studio.

## Daily target
- 1 short video: <= 1 minute
- 1 medium video: 3–5 minutes
- 1 long video: 10+ minutes

## Inputs
Text, images, avatar, existing video, or mixed inputs.

## Holistic pipeline
Prompt → script/storyboard → scene planning → AI visuals → voice-over → captions → music/SFX → automatic editing → quality check → MP4 export.

## Compute
The browser/Android phone is only the control panel. Heavy AI generation is delegated to remote GPU workers through a provider-independent worker interface.

This project is completely separate from the Anteneh Book Store.
