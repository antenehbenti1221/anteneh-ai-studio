# Build roadmap

## Phase 1 — Control plane
- Web UI
- Job API
- Job state model
- Provider-independent GPU worker contract

## Phase 2 — Real remote GPU
- Containerized worker
- GPU health checks
- Queue + retry
- Worker capability routing
- Object storage for assets

## Phase 3 — Open-model production
- Text/image-to-video model worker
- Open TTS worker
- Image generation worker
- Avatar/animation worker
- FFmpeg compositor
- Whisper-compatible captioning

## Phase 4 — Holistic creator workflow
- Script/storyboard planner
- Scene consistency
- Music/SFX
- 9:16, 16:9, 1:1
- Amharic-first voice/caption workflow
- 10+ minute scene orchestration

## Phase 5 — Personal production
- 1 short + 1 medium + 1 long/day target
- History and downloads
- Render presets
- Automatic retries
- Cost/compute dashboard
